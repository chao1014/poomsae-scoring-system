# 品勢電子計分系統 - 硬體與網路需求說明

本文件旨在提供部署與執行「品勢電子計分系統」時所需的硬體配置、設備規格及網路環境建議，以確保比賽期間系統運作流暢、評分數據即時同步且不中斷。

---

## 💻 1. 主控端電腦需求（執行系統主程式與大螢幕投影）

主控電腦負責運行系統主程式（`app.exe`）、Flask/Socket.IO 網頁伺服器，並輸出大螢幕投影畫面至賽場看板。

| 項目 | 最低規格需求 | 建議規格需求 | 說明 |
| :--- | :--- | :--- | :--- |
| **作業系統** | Windows 10 (64-bit) | Windows 10 / 11 (64-bit) | 系統經 PyInstaller 封裝為 Windows 執行檔，目前僅支援 Windows 環境。 |
| **處理器 (CPU)** | Intel Core i3 / AMD Ryzen 3 以上 | Intel Core i5 / AMD Ryzen 5 以上 | 處理器效能會影響大螢幕動畫繪製與 WebSocket 即時通訊的響應速度。 |
| **記憶體 (RAM)** | 4 GB | 8 GB 以上 | 建議預留足夠記憶體以防系統與其他後台程式衝突。 |
| **硬碟空間** | 100 MB 可用空間 | 500 MB 以上 | 主程式體積小，主要空間用於儲存每日比賽日誌與資料庫。 |
| **顯示輸出** | 具有 1 個額外影像輸出埠 (HDMI/DP) | 具有雙影像輸出埠，支援獨立雙螢幕 | 必須將大螢幕投影視窗拖曳至第二螢幕（投影機/LED牆）並全螢幕顯示，主螢幕則留給控分人員操作。 |
| **網路卡** | 100 Mbps 乙太網路卡 或 Wi-Fi | 1 Gbps 有線網路卡 + 雙頻 Wi-Fi | **強烈建議**主控電腦使用實體有線網路連接路由器，以保證與裁判端通訊的穩定度。 |

---

## 📱 2. 裁判端打分設備需求（裁判手機/平板）

裁判端透過網頁瀏覽器開啟評分介面進行即時打分，無需安裝任何 APP。

| 項目 | 最低規格需求 | 建議規格需求 | 說明 |
| :--- | :--- | :--- | :--- |
| **設備類型** | 智慧型手機、平板電腦 | 5 吋以上螢幕之智慧型手機或平板 | 螢幕大於 5 吋可提供更好的按鈕觸控面積，避免誤觸扣分鍵。 |
| **作業系統** | iOS 12+ / Android 8.0+ | iOS 15+ / Android 11+ | 只要能執行現代主流網頁瀏覽器即可。 |
| **網頁瀏覽器** | 支援 WebSockets 協定之現代瀏覽器 | Google Chrome / Apple Safari 最新版 | 必須使用支援 WebSocket 的瀏覽器。請避免使用舊型內建瀏覽器。 |
| **網路連線** | 支援 Wi-Fi | 建議使用 5GHz Wi-Fi | 裁判設備須與主控電腦連接同一個區域網路。 |
| **電力要求** | 電量高於 50% 或備有行動電源 | 充飽電，或接上充電線使用 | 螢幕在評分期間需保持常亮，耗電量較快，建議於裁判席準備行動電源或電源插座。 |

## 🌐 3. 網路環境與設備需求（最關鍵）

由於本系統採用 **WebSocket 即時雙向通訊技術**，裁判每次按下扣分或送出分數時，數據皆為即時傳輸。**網路的穩定度與延遲（Latency）將直接決定計分系統是否會卡頓。**

本系統使用專屬區域網路（Local LAN）運作，不需要外網。主控電腦、裁判手機及比分後台必須能在同一個區域網路中互相連線。

* **無線路由器（AP / Router）需求**：
  * 建議使用雙頻 AC1200 以上的無線路由器。
  * 正式比賽建議使用 5GHz 頻段，降低現場 2.4GHz 干擾。
* **連線配置規範**：
  * 主控電腦建議使用 Cat 6 網路線直接連接路由器 LAN 埠。
  * 裁判手機連接同一台路由器的 Wi-Fi。
  * 比分後台可使用網路線或同一個 Wi-Fi，並允許私人網路 TCP 5004。
  * 路由器必須關閉「AP 隔離／用戶端隔離」，否則裁判、各場地與後台無法互相連線。
  * Wi-Fi 應設定密碼，且不要提供給無關人員。
  * 無線路由器應架高並靠近裁判席與主控台，避開水泥牆與大型金屬障礙物。

## 💡 4. 常見問題與硬體維護建議

1. **大螢幕畫面卡頓或掉幀？**
   * 請確認主控電腦是否已將「大螢幕投影」視窗拖至外接螢幕，並檢查顯示晶片驅動程式是否已更新。
   * 請確認主控電腦是否正進行系統更新（如 Windows Update）或防毒軟體全盤掃描，這會佔用大量處理器效能。

2. **裁判打分送出後，大螢幕很久才更新？**
   * 這通常是因為網路延遲或掉包所致。請確認主機的控制台視窗是否有斷線重連日誌。
   * 請確認裁判手機與主控電腦位於同一個 Wi-Fi，並確認路由器未啟用 AP 隔離。

3. **雙螢幕設定說明**
   * 在 Windows 系統中，按下快捷鍵 `Win + P` 並選擇 **「延伸」** 模式。
   * 啟動 `app.exe` 後，在主控畫面點擊「開啟投影視窗」，將產生的投影視窗拖曳至第二螢幕（即投影機或大螢幕），並按兩下標題列或按「全螢幕」按鈕，使其滿版呈現。
